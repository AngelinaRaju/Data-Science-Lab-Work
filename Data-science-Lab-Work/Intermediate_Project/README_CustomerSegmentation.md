# Customer Segmentation using Clustering

## Description
This project focuses on grouping customers into different segments based on their characteristics such as age, income, and spending behavior. The goal is to identify patterns in customer data to support better business decisions.

## Dataset
- **Source:** Kaggle (Mall Customers Dataset)
- **Description of data:**  
  The dataset contains customer details such as Customer ID, Gender, Age, Annual Income, and Spending Score. These features are used to group similar customers.

## Steps Performed
1. **Data Cleaning**  
   Removed missing values and selected relevant features for analysis.

2. **Exploratory Data Analysis**  
   Analyzed customer distribution based on age, income, and spending score.

3. **Visualization**  
   Used scatter plots and the Elbow Method graph to understand clustering patterns.

4. **Model Building (if applicable)**  
   Applied K-Means clustering algorithm to segment customers into groups.  
   Used silhouette score to evaluate clustering performance.

## Results
- Customers were grouped into distinct clusters based on behavior.
- Identified segments such as high-income high-spending customers.
- Silhouette score used to evaluate clustering quality.

## Tools Used
- Python
- NumPy, Pandas, Matplotlib, Scikit-learn

## Conclusion
Customer segmentation helps businesses understand different types of customers and enables targeted marketing strategies. Clustering techniques like K-Means are effective for identifying hidden patterns in customer data.
